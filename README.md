# 唯一解 · The Only Solution

找出唯一说得通的那个人。三个本格推理案，纯前端网页作品。

## 直接玩

| 入口 | 地址 | 适合 |
|---|---|---|
| GitHub Pages | https://dcd887.github.io/deduction-h5/ | 国内访问快 |
| itch.io | https://dcd2321.itch.io/the-only-solution | 海外 / 移动端 / 可被 itch 社区发现 |

你是一名受委托的调查顾问：勘查现场、询问在场的人、调取记录，然后指认凶手并说清依据。

- 纯静态、零后端、零外部请求，案件数据以编码形式打包在本地
- 存档写在浏览器 localStorage，关掉页面能接着玩；支持回档一步、重置本关
- 三级递进提示，不看提示也能通关
- 手机与桌面都能玩，桌面双击 `index.html` 即可，不需要服务器

## 三个案子

| 案子 | 难度 | 嫌疑人 | 要点 |
|---|---|---|---|
| 案件 001 · 青石巷 17 号 | 普通 | 4 名 | 门从屋里上销、死亡时间被改了两次 |
| 案件 002 · 六楼病房 | 普通 | 4 名 | 监控探头与进修人员的身份缝合 |
| 案件 003 · 听松墅 | 硬核 | 5 名 | 叙述性诡计 |

单案 40–60 分钟，三案合计 2.5–3 小时。

## 说明

- 案内人名、机构名、药品名均为虚构，不对应任何真实个人或单位
- 案件数据以 base64 + 异或编码存储，避免查看源码直接读到凶手（只能挡随手翻源码，不防逆向）
- 代码与案内文本在 AI 辅助下完成，经人工修改与十二轮独立盲推验证
